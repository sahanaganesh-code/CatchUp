Hard Rules Locations
====================

RULE #1: Evidence Requirement (2-5 quotes)
- Enforced in: backend/app/rag.py
- Config: backend/app/config.py (min/max_evidence_quotes)
- UI: frontend/app/components/EvidenceList.tsx

RULE #2: Approval Gating
- Enforced in: backend/app/actions.py
- API: POST /api/actions/approve
- UI: frontend/app/components/ActionsPanel.tsx

RULE #3: Modular Architecture
- Documented in: .cursorrules
- Structure: Separate files for each concern
- See: backend/app/ directory
